# Finanças

App simples de finanças pessoais para casal.

## Stack

- React
- Vite
- Supabase

## Como rodar

```bash
npm install
npm run dev
```

## Configuração

Crie um arquivo `.env` na raiz copiando o `.env.example`:

```env
VITE_SUPABASE_URL=sua_url
VITE_SUPABASE_ANON_KEY=sua_anon_key
```

Depois execute o SQL em `supabase/database.sql` no Supabase SQL Editor.
